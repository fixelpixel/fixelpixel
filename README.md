# Daniil Maximkin

Tracking and analytics engineer in Valencia, Spain. Since 2013 I have been finding out why purchases, leads and revenue go missing or get counted twice, rebuilding the event path across browser, server and backend, and checking each fix order by order against real orders, payments and CRM records.

I also build the software behind that work: Fixel Pixel, a Shopify server-side event product that delivers storefront events to Meta Conversions API, GA4 and Google Ads, plus Shopify apps, API integrations and AI-assisted automation.
